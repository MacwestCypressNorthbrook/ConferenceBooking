## Brand & Style

This design system targets modern enterprises, workplace operations managers, and hybrid teams requiring high-density spatial scheduling. The aesthetic draws direct inspiration from high-craft SaaS tools—marrying the technical rigor of Linear with the kinetic fluidity of Cal.com. 

The emotional tone balances quiet authority, executive readiness, and seamless spatial coordination. The visual language utilizes a refined "Technical Modern" philosophy: ultra-crisp hairline dividers, high visual density without cognitive friction, typographic hierarchy prioritizing data legibility, and subdued chromatic signals that guide action without sensory overload.

## Colors

The palette is engineered around deep architectural indigos, structural slate neutrals, and functional status accents.

- **Primary (`#4338CA` / Indigo-700):** Signifies definitive user intent—active bookings, primary action buttons, time-seeker scrubbers, and focused date nodes.
- **Secondary (`#0F172A` / Slate-900):** Dictates structural grounding—high-contrast headlines, persistent navigation sidebars, and critical metadata headers.
- **Tertiary (`#0D9488` / Teal-600):** Used for physical amenities, hardware availability indicators (e.g., Zoom Rooms, Neat Bar online), and verified automated check-ins.
- **Neutral (`#64748B` / Slate-500):** Anchors secondary body text, non-active room capacities, timeline rule ticks, and empty state guides.

### Semantic Status Tokens
- **Confirmed / Booked:** Emerald (`#059669` fill, `#ECFDF5` background, `#A7F3D0` border).
- **Pending Approval:** Amber (`#D97706` fill, `#FFFBEB` background, `#FDE68A` border).
- **Conflicting / Disputed:** Crimson (`#E11D48` fill, `#FFF1F2` background, `#FECDD3` border).
- **Held / Temporary Release:** Violet (`#7C3AED` fill, `#F5F3FF` background, `#DDD6FE` border).
- **Surface Background:** `#F8FAFC` (Slate-50) for canvas backgrounds, `#FFFFFF` for primary work surfaces and grid blocks.
- **Hairline Borders:** `#E2E8F0` (Slate-200) for standard layout divisions, `#CBD5E1` (Slate-300) for interactive element boundaries.

## Typography

The typographic engine uses **Geist** for crisp graphical clarity across standard UI interfaces and **JetBrains Mono** for temporal, technical, and spatial figures (timestamps, duration readouts, floor coordinates, capacity metrics).
